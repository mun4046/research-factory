# 종목 페이지 템플릿 — `pages/entity-{kr|us}-{code}.md`

파일명: KR은 6자리 코드(`entity-kr-214450.md`), US는 심볼 소문자(`entity-us-nvda.md`).

```markdown
---
title: {회사명} ({KR|US} {코드})
type: entity
market: kr|us
ticker: {코드}
cik: {US만 — 10자리 CIK. Stage 0에서 1회 조회 후 저장. KR은 생략}
status: watchlist|candidate|dormant
tags: [{섹터}, {테마}, ...]
sources: [{관련 위키 페이지}, PlayMCP koreaStock, ...]
created: YYYY-MM-DD
updated: YYYY-MM-DD
---

# {회사명} ({KR|US} {코드})

## 1. 한 줄 요약
{무슨 회사인지 + 지금 왜 보는지. 2문장 이내.}

## 2. 회사 개요 & 펀더멘털
{비즈니스 모델, 매출 구성(비중), 주요 경쟁사, 산업 내 위치. 5~8문장.}

| 지표 | 값 | 출처 · 조회일 |
|---|---|---|
| 현재가 | | |
| 시가총액 | | |
| PER (실적/예상) | | |
| 52주 고/저 | | |
| 리스크 플래그 | {없음 또는 요약} | |

## 3. 추적 이슈 / 촉매
| 예정일 | 이벤트 | 상태 | 예상 영향 |
|---|---|---|---|
| YYYY-MM-DD | 2Q 실적 발표 | 예정 / 완료 / 무산 | |

## 4. 뉴스 & 센티먼트
{최신이 위. 항목 형식 고정:}

{40건을 넘으면 오래된 항목부터 아래 문단 하나로 압축하고 항목은 삭제:}
### 이전 흐름 요약 (~YYYY-MM-DD)

## 5. 변경 이력
- YYYY-MM-DD ({mode}): {무엇이 바뀌었는지 한 줄}. {모순이 있었으면 여기에도 기록}
```

## 작성 규칙

- 섹션 번호·제목은 바꾸지 않는다(배치가 섹션 단위로 갱신한다).
- 섹션 2 지표 표는 5행 고정. 재무제표 전체를 넣지 않는다 — 필요하면 `query-*` 페이지로 분리.
- 섹션 4 항목은 헤드라인 중복 금지. 같은 사건의 후속 보도는 기존 항목 뒤에 `→ 후속: ...` 로 붙인다.
- 갱신 시 `updated`를 오늘로, `sources`에 새 출처를 추가한다.
- 페이지 밖 링크는 `[[페이지명]]`, 외부 URL은 뉴스 항목에만.
